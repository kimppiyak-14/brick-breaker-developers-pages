온라인 명예의 전당 설정

벽돌 깨기 게임을 claude.ai가 아닌 다른 도메인에 올렸을 때, 진짜 온라인 순위표를 쓰기 위한 1회용 설정 도구예요.

  1. jsonbin.io에서 무료로 가입하세요.
  2. 로그인 후 대시보드의 API Keys 메뉴에서 Master Key를 만들고 복사하세요.
  3. 아래 칸에 붙여넣고 버튼을 누르면, 순위표를 저장할 공간(Bin)을 자동으로 만들어드려요.
  4. 결과로 나오는 두 줄을 복사해서, 게임 HTML 파일 안의 JSONBIN_ID / JSONBIN_KEY 부분에 붙여넣고 다시 업로드하세요.

이 키는 게임 파일 안에 그대로 저장되어 누구나 볼 수 있게 돼요. 그래서 마음만 먹으면 다른 사람이 순위 데이터를 조작할 수도 있어요 — 친구들끼리 가볍게 쓰는 용도로만 추천드려요. 무료 요금제는 한 달에 10,000번의 요청을 제공합니다.
